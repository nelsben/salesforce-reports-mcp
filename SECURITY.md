# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Say what you found, how to reproduce it, and which version you used. You will get an answer as soon as it has been looked at.

## Supported versions

Fixes go into the latest release on npm.

## How the server handles access

[Security and identity](docs/security.md) explains who each call runs as, what each tool can change, and how tokens are kept out of logs and files.
